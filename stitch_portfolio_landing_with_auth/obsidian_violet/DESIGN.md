## Brand & Style

This design system expresses a high-end, dark-mode-first aesthetic tailored for elite creative technologists, designer-engineers, and forward-looking digital creators. It pairs the disciplined restraint of architectural minimalism with the atmospheric tension of neon-infused ambient lighting.

The visual direction centers on deep charcoal-to-obsidian depths interrupted by precise violet radiance. The tone is authoritative, understated, and technically sophisticated—prioritizing hyper-focused content hierarchy, crystalline micro-details, and quiet confidence over loud ornamentation. The emotional response evokes stepping into a bespoke studio gallery at midnight: immersive, tactile, focused, and immaculate.

## Colors

The palette leverages a dark luminance model built on stratified shades of carbon, charcoal, and obsidian. Accents avoid gratuitous usage and instead act as precision luminescence.

- **Primary (`#8b5cf6`)**: Electric violet. Reserved for high-value interactive focal points, primary action triggers, active navigation items, and focus indicators.
- **Secondary (`#a78bfa`)**: Neon lavender. Deployed for subtle gradients, hover transitions, ambient glows, and emphasized micro-copy.
- **Tertiary (`#c4b5fd`)**: Luminous lilac. Applied for highlights, delicate icon strokes, and ultra-high-contrast accent moments.
- **Neutral Base (`#0c0d12`)**: Deep obsidian canvas foundation.

Supporting tonal layers:
- **Surface Elevation 1**: `#12151e` (Containers, project cards, and structural grouping).
- **Surface Elevation 2**: `#181c28` (Hover states, input backgrounds, active panels).
- **Subtle Stroke / Border**: `#1e2230` (Ghost dividers, container seams, crisp outlines).
- **Border Active / Highlight**: `#2e354b` (Card hover borders and focused boundaries).
- **Text Primary**: `#f8fafc` (Headlines, crucial text, metric numerals).
- **Text Secondary**: `#94a3b8` (Body prose, metadata, labels, captions).
- **Text Muted**: `#64748b` (Timestamps, disabled treatments, placeholder text).

## Typography

The typographic hierarchy pairs the structured geometric elegance of Plus Jakarta Sans for titles and interface wayfinding with the reading efficiency of Inter for sustained prose and technical details.

- Headings utilize tight negative letter-spacing (`-0.015em` to `-0.03em`) to anchor titles with an editorial, gallery-like gravitas.
- Micro-labels and status indicators use slightly tracked uppercase styling (`+0.04em` to `+0.06em`) in small sizes for crisp, instrument-grade precision.
- Paragraphs run on Inter at generous line heights (`1.55` to `1.6`) against dark backdrops to eliminate optical halation and ensure effortless reading comfort.

## Layout & Spacing

Layouts are structured around a 12-column fluid grid on desktop (max width `1280px`), adapting down to an 8-column layout on tablet screens, and a single-to-two-column system on mobile devices.

- **Breakpoints**: Mobile (`0–639px`), Tablet (`640–1023px`), Desktop (`1024px+`).
- **Rhythm Philosophy**: The system relies on intentional asymmetric whitespace. Primary section breaks use `margin-lg` (`5rem`) to create dramatic breathability between showcase modules, while tight internal component clusters use `space-xs` through `space-md` for mechanical cohesion.
- **Reflow Rules**: Work showcases collapse from 2-column or 3-column masonry grids into stacked full-width vertical showcases on mobile screens. Navigation bars pin to the top or bottom as floating glass pills on mobile viewports.

## Elevation & Depth

Visual depth is achieved through translucent planar layering, soft linear gradients, and radial violet illumination rather than heavy dropshadows.

1. **Surface 0 (Base)**: `#0c0d12` solid canvas.
2. **Surface 1 (Card / Module)**: Linear gradient from `#141722` (top) to `#0f1118` (bottom) bounded by a 1px border stroke (`#1e2230`).
3. **Surface 2 (Floating Popovers / Auth Panels / Modals)**: `#151824` with 80% opacity and `backdrop-filter: blur(16px)`, enclosed by `border: 1px solid rgba(167, 139, 250, 0.15)`.
4. **Neon Violet Aura (Micro-Glow)**:
   - Rest glow: `box-shadow: 0 0 0 1px #1e2230, 0 12px 32px -8px rgba(12, 13, 18, 0.8)`.
   - Active / Hover glow: `box-shadow: 0 0 0 1px rgba(139, 92, 246, 0.4), 0 0 24px -4px rgba(139, 92, 246, 0.25)`.
5. **Backdrop Lighting Elements**: Large, diffuse background radial gradient bursts (`radial-gradient(circle at 50% 0%, rgba(139, 92, 246, 0.08), transparent 70%)`) give headers and spotlight showcases cinematic dimensionality.

## Shapes

The design uses a refined curvature profile (`roundedness: 2` = 0.5rem base) to preserve a sharp architectural posture while preventing digital coldness.

- **Inputs, Buttons, and Chips**: `0.5rem` (8px) for structural crispness.
- **Cards and Dialog Containers**: `rounded-lg` (`1rem` / 16px) to comfortably envelope content without ballooning corners.
- **Full-Bleed Showcase Panels & Modal Shells**: `rounded-xl` (`1.5rem` / 24px) for expansive, framed viewports.
- **Status Badges, Floating Pills, and Icon Avatars**: Fully rounded (`9999px`) for functional visual contrast against angular containers.

## Components

### Buttons
- **Primary**: Violet gradient fill (`linear-gradient(135deg, #8b5cf6, #7c3aed)`), text `#ffffff`, border `1px solid rgba(255, 255, 255, 0.15)`, soft purple drop-shadow. Hover triggers a subtle brightness increase and an ambient outward violet glow.
- **Secondary / Ghost**: Background `#12151e`, border `1px solid #1e2230`, text `#f8fafc`. Hover transitions border to `#2e354b` and background to `#181c28`.
- **Minimal / Link**: Background transparent, text `#a78bfa` with continuous hover transition to `#c4b5fd` accompanied by an animated 1px underline.

### Cards (Portfolio Project & Showcase Modules)
- Constructed with a 1px border (`#1e2230`) and surface fill (`#12151e`).
- Hover effects employ a smooth transition: the 1px perimeter border illuminates to `rgba(139, 92, 246, 0.45)`, accompanied by a fine radial spotlight following the cursor position and a faint upward lift (`translateY(-2px)`).
- Media headers within cards are masked by an inner `8px` corner radius with an inset micro-shadow for inset glass depth.

### Input Fields & Authentication Forms
- **Base State**: Container fill `#0f121a`, border `1px solid #1e2230`, typography `Inter 15px`, placeholder text `#64748b`.
- **Focus State**: Border shifts smoothly to `#8b5cf6` alongside an outer ring glow: `0 0 0 3px rgba(139, 92, 246, 0.2)`. Background remains ultra-dark to keep typed text crisp.
- **Form Card Architecture (Auth Pages)**: Centered glass card (`#12151e` at 85% opacity with 20px blur), framed with a delicate border highlight at the top edge (`linear-gradient(90deg, transparent, rgba(167, 139, 250, 0.4), transparent)`).

### Chips & Filter Tags
- Compact height (`28px`), typography `label-sm` (`11px`, semibold).
- Idle: `#131620`, border `1px solid #1e2230`, text `#94a3b8`.
- Selected: Background `rgba(139, 92, 246, 0.15)`, border `1px solid #8b5cf6`, text `#c4b5fd`.

### Checkboxes & Toggle Switches
- **Checkboxes**: 18px square with a 4px corner radius. Inactive: `#12151e` border `#1e2230`. Checked: `#8b5cf6` with a crisp white check vector mark.
- **Toggle Switches**: 40x22px track. Off: `#181c28` with `#1e2230` border. Active: `#8b5cf6`. Knob transitions seamlessly with an internal soft white highlight.

### Lists & Activity Feeds
- Unbordered list rows separated by a hairline gradient divider (`linear-gradient(90deg, #1e2230 0%, rgba(30, 34, 48, 0.2) 100%)`).
- Metadata (dates, technology tags, view counts) aligned to the right using `label-md` in `#64748b`.

### Status Indicators & Badges
- Floating availability pills (e.g., "Available for Q3 projects") using an active glowing green or violet pulse: an internal 6px dot with an asynchronous expanding ping animation, enclosed in a translucent pill badge (`#151926` with `1px solid #1e2230`).
